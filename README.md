# Алгоритмы сортировки: Пузырёк, Выбор, Вставки

Домашнее задание по теме "Алгоритмы сортировки".

## 📌 Описание
Реализованы три классических алгоритма сортировки на Python. 
Проведено сравнение их производительности на списках разного размера, 
построен график зависимости времени от количества элементов.
